# 🌤️ Weather App

A responsive **Weather Web Application** built using **HTML, CSS, and JavaScript** that provides a simple and user-friendly interface for checking weather information.

The project is also configured as a **Progressive Web App (PWA)**, allowing it to behave like an installable application on supported devices.

## 📌 About the Project

The Weather App is a frontend web application developed to practice and demonstrate modern web development concepts such as:

* HTML page structure
* CSS styling and responsive layouts
* JavaScript functionality
* API-based weather data
* Dynamic DOM manipulation
* Progressive Web App functionality
* Service workers
* Web app manifest configuration

The application provides a clean interface for interacting with weather information.

## ✨ Features

* 🌤️ Weather information display
* 🔍 Location/weather search functionality
* 📱 Responsive design
* ⚡ Dynamic content using JavaScript
* 📲 Progressive Web App support
* 🔄 Service worker integration

## 🔄 How It Works

The application follows a simple frontend workflow:

```text
User
  ↓
Weather Search / Location
  ↓
JavaScript
  ↓
Weather Data
  ↓
Process Response
  ↓
Update Web Page
  ↓
Display Weather Information
```

JavaScript handles the application logic and dynamically updates the user interface based on the available weather information.

## 📱 Progressive Web App

This project includes PWA functionality through:

### `manifest.json`

The manifest provides information such as:

* Application name
* Application icons
* Display configuration
* Start URL
* Theme information

### `service-worker.js`

The service worker can be used for:

* Caching application resources
* Improving loading performance
* Supporting offline functionality
* Enabling PWA behavior

This allows the website to provide an experience closer to a native application.

## 🚀 How to Run the Project

### Option 1 — Run Locally

Clone the repository:

```bash
git clone https://github.com/Pyrothrottler/weather.git
```

Navigate to the project:

```bash

```

Then open:

```text

```

Open the project in Visual Studio Code:
